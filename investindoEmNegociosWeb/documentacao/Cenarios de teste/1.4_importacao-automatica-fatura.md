# 1.4 - Importação automática de fatura

## Objetivo
Validar extração e importação automática de itens da fatura PDF para despesas, com deduplicação e associação de cartão/categoria.

## Pré-condições
- Usuário autenticado com feature `invoice-import.access` (Intermediate+).
- Pelo menos 1 cartão cadastrado.
- Categorias de despesa disponíveis.
- PDF de fatura válido para parser suportado.

## Cenários
1. Importação com sucesso (itens únicos)
- Abrir tela `Despesas` e clicar em `Importar fatura`.
- Selecionar PDF válido.
- Selecionar cartão e categoria.
- Confirmar `Salvar fatura`.
- Resultado esperado:
  - API `POST /api/v1/invoice-import/import` retorna `200`.
  - `created > 0`, `failed = 0`.
  - Lista de despesas atualiza com os lançamentos criados.

2. Importação com categoria opcional vazia
- Repetir fluxo sem selecionar categoria.
- Resultado esperado:
  - Importação concluída sem erro.
  - Despesas criadas sem categoria explícita.
  - Cartão permanece vinculado ao lançamento.

## Cenários de exceção
1. PDF inválido na extração
- Selecionar arquivo não-PDF ou PDF corrompido.
- Resultado esperado:
  - API responde com erro (`400` para formato inválido ou `422` para PDF inválido/protegido).
  - UI exibe mensagem de falha e não habilita importação.

2. Importação sem cartão selecionado
- Carregar prévia e tentar salvar sem cartão destino.
- Resultado esperado:
  - Botão de salvar permanece desabilitado no front.
  - Nenhuma chamada de importação é realizada.

## Cenário de regressão
1. Reimportação do mesmo PDF com `skipDuplicates=true`
- Importar uma fatura já importada anteriormente.
- Resultado esperado:
  - Itens já existentes entram como `skipped`.
  - Não duplica lançamentos existentes.
  - Fluxo continua importando apenas itens novos.

## Critérios de aceite
- [ ] Extração de PDF retorna total/datas/itens quando arquivo é válido.
- [ ] Importação persiste despesas com cartão e data de competência corretos.
- [ ] Deduplicação evita duplicidade em reimportação.
- [ ] Casos de exceção validados.
- [ ] Regressão validada.
