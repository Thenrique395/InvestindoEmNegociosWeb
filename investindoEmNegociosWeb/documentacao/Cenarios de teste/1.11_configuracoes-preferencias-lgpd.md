# 1.11 - Configurações (Preferências + Exclusão de Conta LGPD)

## Objetivo
Validar a personalização completa de notificações e o fluxo de exclusão self-service da conta.

## Pré-condições
- Usuário autenticado no perfil `Basic` (ou superior).
- Tela `Configurações pessoais` acessível.
- Usuário com senha válida conhecida para teste.

## Cenários de sucesso
1. Atualizar preferências de notificação completas
- Passos:
  - Abrir `Configurações`.
  - Alterar canais (`in-app`, `email`) e regras (`upcoming`, `overdue`, `daysBeforeDue`).
  - Salvar.
  - Consultar `GET /api/v1/preferences`.
- Resultado esperado:
  - Resposta reflete todos os campos atualizados.
  - Tela mantém os valores após refresh.

2. Excluir conta com confirmação válida
- Passos:
  - Informar senha atual correta.
  - Informar texto `EXCLUIR`.
  - Acionar `Excluir minha conta`.
- Resultado esperado:
  - API responde `204 NoContent` em `POST /api/v1/preferences/account/delete`.
  - Sessão é encerrada no frontend.
  - Usuário é redirecionado para login.

## Cenários de exceção
1. Tentativa de exclusão com senha inválida
- Passos:
  - Informar senha incorreta.
  - Informar `EXCLUIR`.
  - Confirmar exclusão.
- Resultado esperado:
  - API responde `400`.
  - Mensagem: `Senha inválida`.
  - Conta e dados permanecem intactos.

2. Tentativa de exclusão sem texto de confirmação correto
- Passos:
  - Informar senha correta.
  - Informar texto diferente de `EXCLUIR`.
  - Confirmar exclusão.
- Resultado esperado:
  - API responde `400`.
  - Mensagem orientando confirmação explícita.
  - Conta e dados permanecem intactos.

## Cenário de regressão
1. Preferências antigas continuam funcionando
- Passos:
  - Alterar apenas `in-app` e `email`.
  - Salvar.
  - Reabrir tela.
- Resultado esperado:
  - Campos antigos continuam persistindo.
  - Inclusão dos novos campos não quebra o fluxo existente.

## Critérios de aceite
- [ ] `GET/PUT /preferences` funcionando com todos os campos de notificação.
- [ ] `POST /preferences/account/delete` funcionando com senha + confirmação.
- [ ] Casos de exceção (senha inválida/confirmacão inválida) validados.
- [ ] Regressão de preferências básicas validada.
